# Dashtext on GPUI: version 1 scope

Date: 2026-09-29

## Why a rewrite

The Tauri + SvelteKit app carried a web stack (CodeMirror, Drizzle, a separate web build, an updater) for what is a small native utility. Version 0.4 replaces it with a single Rust workspace on GPUI and GPUI Component (`gpui-kit` 0.7, Longbridge). Nothing is preserved except the intent: an open-source, cross-platform Drafts.

## What Drafts does (iOS and macOS)

Sources: docs.getdrafts.com (Drafts, Tagging, Workspaces, Actions, Capture window), scripting.getdrafts.com (`Draft` class), MacStories' Drafts for Mac review, the iOS changelog.

**Draft model**

- `uuid`, `content` (one plain-text string, usually Markdown), `createdAt`, `modifiedAt`, an accessed date, created/modified location, `syntax`, persisted selection.
- Title is derived, never stored: the first line; `displayTitle` strips Markdown heading markers.
- Exactly one folder: `inbox`, `archive` or `trash`. New drafts land in the inbox. Trash is purged manually or after 30 days.
- `isFlagged` is independent of the folder. List tabs are Inbox, Flagged, Archive, All (inbox + archive) and Trash; Flagged and All are views, not folders.
- Tags: lowercase strings, nested with `/`, scoped with `::`.
- Versions: automatic history, plus manual snapshots.

**Capture**

- The app opens to a new blank draft; "new draft after N minutes away".
- macOS capture window: a small floating window with a global hotkey. It keeps its text until saved or cleared; `⌘↩` saves to the inbox; it can flag.
- Menu bar and Dock entries for new draft, capture, and capture-from-clipboard.

**List**: per-tab sort (created/modified/accessed), preview lines, flagged handling, search with `"phrases"` and `-exclusions`, tag filters with any/all/not.

**Workspaces**: saved list configurations — search, tag and date filters, per-tab sort, flagged handling, preview options, the active tab, an action group and a theme.

**Actions**: ordered steps (system, services, utility, advanced); the Script step is JavaScript against the Drafts API; templates use tags and Mustache; action groups, action bar, keyboard shortcuts, action log.

**Other**: Markdown syntaxes and preview, themes, focus mode, typewriter scrolling, link mode, arrange mode, `[[wiki links]]`, statistics, URL scheme, Shortcuts, iCloud sync.

## Version 1 (this release)

| Area | Included |
| --- | --- |
| Data | Draft = id (UUIDv7), Markdown content, folder, flag, created/modified/accessed/trashed times. Derived title and preview. SQLite with `user_version` migrations, WAL, XDG data dir. |
| Intake | Inbox as the central intake folder; Flagged, Archive, All and Trash views; counts in the sidebar; 30-day trash purge. |
| Capture | Quick capture window (`dashtext capture`, `Ctrl+Shift+N`), `Ctrl+Enter` saves to the inbox and closes, `Esc` closes and keeps the text (persisted across restarts), flag toggle. |
| Editing | Always a draft ready to type into; autosave; empty drafts discarded; word and character counts; trash is read-only. |
| Processing | Flag, archive/unarchive, trash/restore with undo notifications; permanent delete and empty trash with confirmation. |
| Finding | Search with required words, phrases and exclusions; keyboard navigation of the list. |
| Desktop | Single instance (Unix socket), `dashtext new` for scripts, app menus with shortcuts, custom title bar, desktop entry with a Quick Capture action, light/dark from the system. |
| Room to grow | `Workspace` (scope + sort, JSON so filters can be added without migrations); `dashtext-core` has no UI dependency, for an actions runtime, sync, and mobile front ends. |
